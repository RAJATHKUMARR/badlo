# Badlo

**Change any file, right on your PC.**

Badlo is a free Windows app that converts photos, PDFs, Word, Excel, PowerPoint, videos, music and zip files. Select a file in File Explorer, press **Ctrl + Space**, and pick a format. Nothing is uploaded: every conversion happens on your computer.

## Download

Get the latest installer from **[getbadlo.netlify.app](https://getbadlo.netlify.app)** or the [Releases page](https://github.com/RAJATHKUMARR/badlo/releases/latest).

Windows may show a blue "Windows protected your PC" box because Badlo is new. Click **More info**, then **Run anyway**. Badlo updates itself after that.

## Report a problem

In the app: Settings → Report a problem. Or use the form on [the website](https://getbadlo.netlify.app/#report).
